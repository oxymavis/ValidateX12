PowerMax 856 校验说明整理版

1. 文档目的

本文档基于 PowerMax校验.docx 整理，目的是将当前 PowerMax 856 项目的客户识别规则、报文归属结果以及样例 ASN 校验结论统一整理为一份清晰、可读、便于人工审阅和后续维护的说明文档。

本文档主要用于：

  • 根据 ISA/GS 信息识别 retailer
  • 判断一份 ASN 应使用哪个 retailer 的校验 spec
  • 快速查看当前生成 ASN 的主要错误与警告
  • 为后续修正 mapping、HL 结构、字段拼装逻辑提供依据

2.3 判断原则

  1. 主判断依据是 ISA 和 GS 中的 qualifier、sender/receiver ID 与版本号。
  2. N1 名称、客户显示名只作为辅助信息，不作为第一优先级。

4. 各 Retailer ASN 校验结果汇总

5. Amazon Warehouse

5.1 文件

AMAZON-0074072_79HFKDZP_20260311181704.edi

5.2 去重后的主要报错

Error

  • GS01 必须是 SH
  • BSN04 必须是 HHMMSS
  • 缺少 shipment 级 DTM*011
  • 缺少 shipment 级 DTM*017
  • Ship To N103 不符合要求，必须是 15/92/UL
  • 缺少 Ship To N104
  • Ship From N103 不符合要求，必须是 1/15/92/UL/ZZ
  • 缺少 Ship From N104
  • Package 层缺少 REF*CN
  • item 层缺少 LIN03
  • item 层 SN103 不是 CA 或 EA，实际更像是缺失

Warning

  • 出现了 import-only 的 TD3
  • REF*BM 是 TL/LTL 条件字段提醒
  • Ship To N102 被使用，但 PDF 标为 not used
  • Ship From N102 被使用，但 PDF 标为 not used
  • LIN 中出现额外 qualifier：BP/UP/UK/UA/SKU。按当前 Amazon PDF 严格校验会提示，但不一定代表业务上绝对错误。

5.3 结论

  1. 头部和 shipment 基础段不符合 Amazon 856：GS01/BSN04/DTM/N1
  2. package 层缺少关键 tracking 字段：REF*CN
  3. item 层 LIN/SN1 关键字段不完整

6. Burlington Coat Factory

6.1 文件

Burlington-0073894_384562802_20260311181739.edi

6.2 去重后的主要报错

Error

  • GS01 不是 SH，当前是 SW
  • TD3 缺少 TD303 equipment number
  • LIN02 不是 Burlington 允许的 EN/IN/UK/UP
  • 缺少 LIN03 item ID
  • LIN04 不符合该位置允许值 IT
  • LIN06 不符合该位置允许值 BO
  • 使用了 LIN06 时缺少 LIN07
  • LIN08 不符合该位置允许值 IZ
  • 使用了 LIN08 时缺少 LIN09
  • LIN10 不符合该位置允许值 PU
  • 使用了 LIN10 时缺少 LIN11
  • LIN12 不符合该位置允许值 BL
  • SN103 必须是 AS 或 EA

Warning

  • shipment 级 TD101 不在允许值 BAG/CTN/SLP/SRW 中
  • 出现 Burlington 规范外的 REF01='23'
  • 国家代码用了 USA，建议使用 US

6.3 结论

  1. 头部功能组错误：GS01=SW
  2. shipment 级运输信息不完整：TD3/N4/REF
  3. item 级 LIN/SN1 结构明显不符合 Burlington 856 规范

7.1 文件

7.2 主要报错

Error

  • Functional group for 856 must be SH (got 'SW')
  • 缺少 shipment 级 DTM
  • 出现不支持的 HL03='T'
  • Pack HL 的父级不是 Order HL
  • 缺少 pack 级 LIN
  • 缺少 pack 级 SN1
  • 缺少 item 级 LIN03
  • Item SN103 必须是 EA

  1. 头部 GS01 不符合规范
  2. HL 层级结构不符合 DSD profile
  3. shipment 级缺关键日期段
  4. pack/item 级字段生成方式与 Delhaize sample/profile 不一致

  4. PO4 也缺少成对字段

10. 共性问题汇总

10.1 头部问题

  • 多个文件将 GS01 生成成了 SW，但 856 应为 SH
  • 部分文件 GS08 与目标 spec 版本不匹配

10.2 HL 结构问题

  • 不同 retailer 对 S/O/P/I 或 S/O/T/P/I 的要求不同
  • 当前生成逻辑在 Delhaize、Topco/SPS 等场景下，仍存在层级结构不匹配

10.3 Shipment 级段问题

  • DTM、PER、REF、TD3 等段缺失或元素不完整
  • N1/N4 的 qualifier、国家代码、标识符字段不符合客户规范

10.4 Item 级段问题

  • LIN 的 qualifier/value 成对规则经常不满足
  • SN103 单位代码与 retailer spec 不一致
  • PO4 的成对字段缺失较常见

11. 建议修正顺序

  1. 先修正 envelope 和头部字段：GS01、GS08、ISA/GS 与 retailer mapping 的对应关系
  2. 再修正 HL 结构模板：不同 retailer 使用不同 HL 模板，避免一个通用模板硬套全部客户
  3. 再修正 shipment/order 级必填段：DTM、PER、PRF、REF、N1/N4、TD3
  4. 最后修正 item 级字段拼装：LIN 成对输出、SN103 单位按客户规范输出、PO4 成对字段完整输出
